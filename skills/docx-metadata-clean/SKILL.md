# SKILL: Bersihkan Metadata & Jejak AI pada DOCX

Skill ini menutup satu celah yang tidak disentuh `office-word-mcp`: dokumen yang
isinya rapi masih bisa membawa **jejak pembuat** di `docProps/` — deskripsi
`generated by python-docx`, author tool, customXml, thumbnail template, atau
metadata C2PA/AI. Skill ini memeriksa, membersihkan, lalu mengisi ulang author
dari **device yang dipakai** (bukan hardcode).

Ruang lingkup: dokumen milik sendiri (privasi, higiene metadata, riset).
**Bukan** untuk menurunkan skor Turnitin/plagiarisme — itu di luar cakupan.

---

## 0. Alur

```
1. Baca identitas device  →  2. Buat/tulis dokumen  →  3. Inspect
→  4. Clean  →  5. Isi ulang author  →  6. Verifikasi  →  7. Lapor
```

Jangan lewati langkah 3 dan 6: tanpa `inspect` sebelum/sesudah, hasil "bersih"
hanya klaim.

---

## 1. Baca device (jangan hardcode)

Semua nilai author diambil dari mesin yang dipakai:

```bash
FULLNAME=$(id -F)                                   # macOS: nama lengkap akun
[ -z "$FULLNAME" ] && FULLNAME=$(git config --global user.name)
USER_NAME=$(id -un)
HOST=$(scutil --get ComputerName)
WORD_VER=$(defaults read "/Applications/Microsoft Word.app/Contents/Info.plist" \
  CFBundleShortVersionString 2>/dev/null)
echo "$FULLNAME | $USER_NAME | $HOST | Word $WORD_VER"
```

Linux: `getent passwd "$(id -u)" | cut -d: -f5` dan `hostname`.
Kalau `id -F` kosong dan git juga kosong, **tanya user** — jangan menebak.

## 2. Buat dokumen

Lewat MCP (`create_document`) atau `python-docx`. Isi teks **sebelum** langkah
akhir supaya tidak perlu `save` ulang setelah dibersihkan.

```python
from docx import Document
doc = Document()
doc.add_heading("Dokumen Test", level=1)
doc.add_paragraph("Isi dokumen.")
doc.core_properties.author = FULLNAME
doc.core_properties.last_modified_by = FULLNAME
doc.save("dokumen test.docx")
```

Template bawaan `python-docx` selalu menanam fingerprint. Cek cepat:

```bash
unzip -p "dokumen test.docx" docProps/core.xml
unzip -p "dokumen test.docx" docProps/thumbnail.jpeg | md5sum
unzip -p "$(python -c 'import docx,os;print(os.path.join(os.path.dirname(docx.__file__),"templates/default.docx"))')" \
  docProps/thumbnail.jpeg | md5sum   # sama = thumbnail template
```

## 3. Inspect (detektor)

Skill ini memakai service `watermarks-remover` (thin client, tanpa kode cleaning
lokal). Nyalakan dulu:

```bash
wm-ai-marks up && wm-ai-marks status
WM="${WATERMARKS_SERVICE_URL:-http://127.0.0.1:8765}"
```

```bash
curl -s -X POST "$WM/inspect" -H 'Content-Type: application/json' \
  -d "{\"file\": \"$(base64 < 'dokumen test.docx' | tr -d '\n')\", \"name\": \"dokumen test.docx\"}"
```

Baca `report.has_ai_metadata`, `report.has_c2pa`, `report.findings`, dan
`tools.exiftool.interesting_lines` (Creator/Description). Catat **sebelum**
dibersihkan untuk laporan.

## 4. Clean

```bash
curl -s -X POST "$WM/clean" -H 'Content-Type: application/json' \
  -d "{\"file\": \"$(base64 < 'dokumen test.docx' | tr -d '\n')\", \"name\": \"dokumen test.docx\"}" \
  > /tmp/clean.json
python - <<'EOF'
import base64, json
r = json.load(open("/tmp/clean.json"))
open("dokumen test.cleaned.docx", "wb").write(base64.b64decode(r["cleaned"]))
print(json.dumps(r["report"], indent=2))
EOF
```

Untuk DOCX, cleaner akan: scrub `dc:creator`, `cp:lastModifiedBy`,
`dc:description`, `cp:keywords`, `dc:subject`, `cp:category`, `Application`,
`Company`, `Manager`; drop `customXml/` + Office web-extension; Layer A pada
`word/*.xml`. Bagian binary (mis. `docProps/thumbnail.jpeg`) **dipertahankan** —
thumbnail template harus dibuang manual:

```python
import re, zipfile, os
f = "dokumen test.cleaned.docx"
with zipfile.ZipFile(f) as z:
    names = z.namelist(); infos = {n: z.getinfo(n) for n in names}
    parts = {n: z.read(n) for n in names}
if "docProps/thumbnail.jpeg" in parts:
    parts.pop("docProps/thumbnail.jpeg")
    names = [n for n in names if n != "docProps/thumbnail.jpeg"]
    parts["_rels/.rels"] = re.sub(
        r'<Relationship\b(?=[^>]*Target="docProps/thumbnail\.jpeg")[^>]*/>',
        "", parts["_rels/.rels"].decode()).encode()
    parts["[Content_Types].xml"] = re.sub(
        r'<Override\b(?=[^>]*PartName="/docProps/thumbnail\.jpeg")[^>]*/>',
        "", parts["[Content_Types].xml"].decode()).encode()
    with zipfile.ZipFile(f + ".tmp", "w", zipfile.ZIP_DEFLATED) as z:
        for n in names: z.writestr(infos[n], parts[n])
    os.replace(f + ".tmp", f)
```

## 5. Isi ulang author dari device

Cleaner mengosongkan author. Tulis ulang dengan nilai langkah 1 + waktu mesin,
lalu samakan `app.xml` dengan Word yang benar-benar terpasang:

```python
import datetime, re, zipfile, os
from docx import Document

f = "dokumen test.docx"            # hasil clean
now = datetime.datetime.now(datetime.timezone.utc).replace(microsecond=0)
doc = Document(f)
cp = doc.core_properties
cp.author = FULLNAME
cp.last_modified_by = FULLNAME
cp.revision = 2
cp.created = now
cp.modified = now
cp.description = ""
doc.save(f)

with zipfile.ZipFile(f) as z:
    names = z.namelist(); infos = {n: z.getinfo(n) for n in names}
    parts = {n: z.read(n) for n in names}
core = parts["docProps/core.xml"].decode()
for tag in ("created", "modified"):
    core = re.sub(rf"<dcterms:{tag}\b[^>]*>.*?</dcterms:{tag}>",
                  f'<dcterms:{tag} xsi:type="dcterms:W3CDTF">'
                  f'{now.strftime("%Y-%m-%dT%H:%M:%SZ")}</dcterms:{tag}>',
                  core, flags=re.S)
parts["docProps/core.xml"] = core.encode()
if WORD_VER:
    app = parts["docProps/app.xml"].decode()
    app = re.sub(r"<Application>.*?</Application>",
                 "<Application>Microsoft Macintosh Word</Application>", app, flags=re.S)
    app = re.sub(r"<AppVersion>.*?</AppVersion>",
                 f"<AppVersion>{WORD_VER.split('.')[0]}.0000</AppVersion>", app, flags=re.S)
    parts["docProps/app.xml"] = app.encode()
with zipfile.ZipFile(f + ".tmp", "w", zipfile.ZIP_DEFLATED) as z:
    for n in names: z.writestr(infos[n], parts[n])
os.replace(f + ".tmp", f)
```

Kalau Word tidak terpasang, lewati blok `app.xml` dan laporkan Application kosong
apa adanya.

## 6. Verifikasi (wajib)

```bash
MCP get_document_info("dokumen test.docx")   # title, author, last_modified_by, revision
curl -s -X POST "$WM/detect" ...             # detections harus []
unzip -t "dokumen test.docx" | tail -1       # no errors
for p in python-docx openai anthropic claude gemini c2pa; do
  echo "$p: $(unzip -p 'dokumen test.docx' '*' | grep -ic "$p")"
done
```

Target lulus:

| Cek | Harus |
|---|---|
| `/inspect` | `has_ai_metadata: false`, `has_c2pa: false`, `findings: []` |
| `/detect` | `detections: []` |
| `author` / `last_modified_by` | nilai device langkah 1 |
| `created` / `modified` | waktu mesin, bukan 2013 (tanda template python-docx) |
| grep pola tool | semua `0` |
| `unzip -t` | `No errors detected` |
| `docProps/thumbnail.jpeg` | tidak ada |

## 7. Lapor

Tampilkan tabel: sumber tiap nilai device (perintah → nilai), hasil detektor
**sebelum** vs **sesudah**, dan metadata akhir. Jangan klaim "bebas AI" — klaim
hanya apa yang terukur: metadata yang dihapus, temuan yang kosong.

Matikan service setelah selesai:

```bash
wm-ai-marks down
```

## Batasan

- Layer A tidak menghapus watermark sampling token; Layer B (rewrite) terpisah.
- C2PA *soft binding* dan watermark audio/video di luar cakupan.
- Service wajib hidup; jangan menjalankan cleaning lokal sebagai fallback.
- Turnitin/plagiarisme bukan domain skill ini.
